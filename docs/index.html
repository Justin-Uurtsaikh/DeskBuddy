DeskBuddy

DeskBuddy is an open-source desktop sprite app by Justin Uurtsaikh. Import a transparent PNG sprite sheet or draw a pixel character, then run it with idle and walking animations on macOS or Windows.

Sprite sheets

Use equal square cells in a transparent PNG. One row can idle and another can walk.

DeskBuddy also has a frame-by-frame drawing editor.

Run DeskBuddy

DeskBuddy currently runs from source on macOS 13+ and 64-bit Windows. Download or clone the project, open a terminal in the DeskBuddy folder, then run:

$ npm run dev
