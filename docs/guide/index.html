Prepare a transparent PNG sprite for Deskprite

Set up Justin Uurtsaikh’s Deskprite app, import a transparent PNG sprite sheet or draw frames, and launch the animated sprite on your desktop.

On this page

Install and run Deskprite

After downloading or cloning the Deskprite repository, open a Terminal or PowerShell window in the project folder. You will need the following:

  • Node.js 22.12 or newer to install and launch the Electron app.
  • macOS 13 or newer on Intel or Apple silicon, or 64-bit Windows.
$ npm install
$ npm run dev
Download source (.zip) Open the repository
First launch: Electron may download its desktop runtime the first time you run the app, so that first start can take a little longer.

Format the sheet as equal square cells

A simple layout uses four idle frames across the first row and four walk frames across the second. Each cell should contain one complete pose with the same canvas size.

Idle
Walk

In Deskprite

  1. Choose Import sprite sheet.
  2. Select the original transparent PNG—not a screenshot of it.
  3. Pick the suggested grid that places one complete pose in each cell.
  4. Set the idle row, starting column, and frame count.
  5. Do the same for the walk loop, then check the preview.

Image requirements

  • Transparent PNG format
  • Real transparent pixels
  • Visible artwork in each clip
  • Up to 5 MB per source image
  • Up to 16 megapixels
  • Up to 8 frames per clip
Avoid: white backgrounds, screenshots with a checkerboard pattern, labels, borders, or grid lines. Those pixels would become part of your buddy.

Draw frames in the editor

Switch to Draw your own. The canvas starts transparent, so erasing restores transparency instead of painting white.

  1. Draw at least one visible Idle frame.
  2. Use Add frame for the next pose in the loop.
  3. Turn on Previous frame for an onion-skin reference while drawing.
  4. Switch to Walk and make at least one visible movement frame.
  5. Preview the result, then adjust the buddy’s name and size.
Onion skin is only a guide. The faded previous frame is never saved into your finished artwork.

Create and launch the sprite

Select Create & launch. Only your transparent sprite appears on the desktop—there is no card, toolbar, white box, or visible window frame around it.

  • The sprite uses its walk frames while moving and its idle frames while stopped.
  • A sprite that leaves one edge of the screen returns from the opposite edge.
  • You can launch and manage multiple sprites.
  • Use the Deskprite tray menu to reopen the creator or quit.

Troubleshooting

The buddy has a white or checkerboard box

The source image contains those pixels. Export the sprite again with a genuinely transparent background and upload the original PNG file.

The grid cuts through the character

Choose a different suggested grid, or confirm the source sheet uses equal square cells with consistent spacing.

The animation uses the wrong frames

Check the row number, starting column, and frame count for both idle and walk. Row and column numbers begin at 1.

The first run takes a while

Electron may fetch its desktop runtime the first time its command runs. Keep the Terminal window open and let that download finish.

Check the source files

$ npm run check
